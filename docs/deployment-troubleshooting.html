2. 启动流程与命令

一键启动

REM 双击或在 PowerShell 执行
.\start_local.cmd

启动顺序：SNMP 模拟器 → LibreNMS Web 服务。脚本会自动轮询等待就绪。

启动 SSH 拓扑模拟器（按需）

_tools\php74\php.exe _tools\bin\ssh_mock.php

SSH mock 用于演示"SNMP 不通时通过 SSH 发现拓扑"。监听 127.0.0.2-4:2222。

执行 SSH 拓扑发现

_tools\php74\php.exe _tools\bin\ssh_topology.php --start=127.0.0.2

从 127.0.0.2 开始 BFS 遍历，将 LLDP 邻居链路写入 links 表（protocol='ssh-lldp'）。

重置数据库

.\reset_local.cmd

停止服务

.\stop_local.cmd

3. SNMPv3 安全配置

为什么不用 SNMPv2c？

  • 不安全 SNMPv2c 使用明文 community 字符串，抓包即可获取读写权限。
  • 推荐 SNMPv3 提供认证（auth）和加密（priv），数据不可窃听、不可篡改。

v3 凭证（本环境）

参数值说明
Security LevelauthPriv认证 + 加密
Usernamelibrenms
Auth ProtocolSHA (HMAC-SHA-96)
Auth PasswordAuthPass123
Priv ProtocolAES (AES-128-CFB)
Priv PasswordPrivPass456

命令行测试 v3

_tools\php74\php.exe _tools\bin\netsnmp_wrap.php snmpget ^
  -v3 -u librenms -a SHA -A AuthPass123 -x AES -X PrivPass456 -l authPriv ^
  -On 127.0.0.2:11611 .1.3.6.1.2.1.1.1.0

配置位置

  • 模拟器用户定义：_tools/snmp_sim/devices.php → 每个设备的 v3 字段
  • 模拟器入口：_tools/snmp_sim/run.php → SnmpAgent::setV3Users()
  • LibreNMS 默认凭证：LibreNMS-offline/src/lnms/config.php → $config['snmp']['v3']
  • 设备级凭证：SQLite devices 表 → snmpver='v3', authlevel='authPriv' 等

生产环境安全建议

  1. 使用 authPriv 级别，不要用 noAuthNoPriv 或 authNoPriv。
  2. 认证算法优先选 SHA-256 / SHA-512（本模拟器演示用 SHA-96）。
  3. 加密算法选 AES-256（本模拟器演示用 AES-128）。
  4. 密码至少 12 位，包含大小写、数字、符号。
  5. 通过 ACL 限制 SNMP 端口（UDP 161）仅允许监控服务器访问。
  6. 定期轮换 SNMPv3 用户密码。

4. SSH 拓扑发现

使用场景

当网络设备未开启 SNMP 或 SNMP 不通时，可通过 SSH 登录设备执行 LLDP 命令，递归发现邻居并绘制拓扑。

工作流程

  1. 从 --start 指定的设备 SSH 登录
  2. 按厂商执行 LLDP 命令（Cisco/Huawei/HP 各不同）
  3. 解析输出，提取邻居 chassisId / portId / sysName
  4. 将可管理的邻居入队继续 BFS 遍历
  5. 把所有链路写入 LibreNMS links 表，protocol='ssh-lldp'

厂商 LLDP 命令

厂商命令
Ciscoshow lldp neighbors detail
Huaweidisplay lldp neighbor
HP / H3Cshow lldp info remote-device

真实设备接入

当前 sshExec() 使用 fsockopen 连接 mock 端点。接入真实设备时，替换为 phpseclib：

$ssh = new \phpseclib\Net\SSH2($host, 22);
$ssh->login($user, $pass);
$output = $ssh->exec($cmd);

6. 常见问题排查

问题 SNMP 模拟器未响应

现象：start_local.cmd 报 "SNMP 模拟器未响应"。

排查：

  1. 确认 _tools/snmp_sim/run.php 进程在运行
  2. 检查端口 11611 是否被占用：netstat -ano | findstr 11611
  3. 手动启动查看报错：
    _tools\php74\php.exe _tools\snmp_sim\run.php
  4. 确认 PHP 已加载 php_snmp.dll 和 php_sockets.dll 扩展

问题 SNMPv3 认证失败

现象：v3 查询返回空或 "Timeout"。

排查：

  1. 确认凭证一致：-u librenms -A AuthPass123 -X PrivPass456
  2. 确认 -a SHA -x AES -l authPriv 参数齐全
  3. 检查模拟器日志是否打印 "SNMPv3 users configured: librenms"
  4. v3 使用 raw UDP 实现，确认防火墙未拦截 127.0.0.2-4 的 11611 端口

问题 SSH mock 连接失败

现象：ssh_topology.php 报 "FAILED to connect"。

排查：

  1. 确认 ssh_mock.php 已启动并监听 2222
  2. 确认 PHP 已加载 php_sockets.dll
  3. 测试连接：Test-NetConnection -ComputerName 127.0.0.2 -Port 2222
  4. mock 为单连接顺序处理，避免并发连接

问题 Web 页面无法访问

现象：浏览器访问 http://127.0.0.1:5656 无响应。

排查：

  1. 确认 PHP 内置服务器进程在运行
  2. 检查端口 5656：netstat -ano | findstr 5656
  3. 查看 logs/librenms.log 是否有 PHP 错误
  4. 手动启动：
    cd LibreNMS-offline\src\lnms
    ..\..\_tools\php74\php.exe -S 127.0.0.1:5656 -t html server.php

问题 MIB 模块找不到警告

现象：命令行输出大量 "Cannot find module (IP-MIB)" 等。

说明：这是 PHP SNMP 扩展的 MIB 搜索路径警告，不影响功能。本环境通过 netsnmp_wrap.php 使用数字 OID 绕过。可忽略或设置环境变量：

$env:MIBDIRS="e:\IT-network-Rack-Cable-trae\LibreNMS-offline\src\lnms\mibs"

问题 拓扑图不显示链路

排查：

  1. 确认 ssh_topology.php 已执行并写入 links 表
  2. 查询验证：SELECT COUNT(*) FROM links WHERE protocol='ssh-lldp'
  3. LibreNMS 拓扑页面可能需要刷新缓存，重新访问 /map/dependency

日志位置

  • LibreNMS 日志：logs/librenms.log
  • 轮询器日志：logs/poller_wrapper.log
  • SNMP 模拟器：启动窗口输出
  • SQLite 数据库：LibreNMS-offline/src/lnms/storage/librenms.sqlite
